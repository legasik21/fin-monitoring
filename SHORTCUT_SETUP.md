# 📱 Швидке додавання витрат з головного екрана iPhone (Apple Shortcut)

Цей застосунок надає endpoint `/api/quick-add`, який дозволяє додати витрату або дохід **одним дотиком** з головного екрана iPhone — через застосунок **Команди (Shortcuts)**. Нативний iOS-віджет із вебзастосунку зробити неможливо, тому Apple Shortcuts — це правильний підхід.

> Веб-віджет не може писати в застосунок напряму, тому використовуємо Shortcut, який робить HTTP-запит до API.

---

## Що знадобиться

| Значення | Де взяти |
|----------|----------|
| `<DOMAIN>` | `fin-mon.cyberskill.online` (домен розгорнутого застосунку) |
| `<ВАШ_КЛЮЧ>` | ⚙️ **Налаштування** → **⚡ Швидке додавання (Apple Shortcuts)** → **🔑 Згенерувати ключ** (показується один раз) |

> ⚠️ Ключ — це персональна аутентифікація до вашого акаунту. Не діліться ним і не публікуйте. Якщо забули, заново згенеруйте його в Налаштуваннях.

Endpoint приймає JSON із назвою категорії (як у списку в Налаштуваннях) або її id:

```json
{
  "category": "Їжа",
  "amount": 250,
  "note": "кава в кав'ярні",
  "kind": "expense"
}
```

Поля:
- **`category`** (обовʼязково): назва категорії так, як у Налаштуваннях (регістр і пробіли по краях не важливі; категорія має бути активною) або числове id (видно лише через `GET /api/categories` з JWT)
- **`amount`** (обовʼязково): число > 0
- **`note`** (необовʼязково): текст до 200 символів
- **`kind`** (необовʼязково): якщо назва збігається з обома активними категоріями (доходу і витрат), вкажіть `"income"` або `"expense"`

## Побудова Shortcut крок за кроком

Відкрийте застосунок **Команди (Shortcuts)** → **+** (новий Shortcut) → **Додати дію**.

### 1. Запитати суму

- Додайте дію **«Запитати ввід» (Ask for Input)**.
- Тип вводу: **Число (Number)**.
- Підказка (Prompt): **`Сума?`**

### 2. Вибрати категорію

- Додайте дію **«Вибрати з меню» (Choose from Menu)**.
- Пункти меню (Add new item): включіть ваші активні категорії зі своїх Налаштувань (за замовчуванням: **Дохід**, **Витрати**).
- У **кожній** гілці меню додайте дію **«Задати змінну» (Set Variable)**:
  - назва змінної: `category`
  - значення — назва категорії так, як вона відображається в Налаштуваннях (регістр і пробіли по краях не важливі; категорія має бути активною)

  **Приклад** (якщо у Налаштуваннях ви створили такі категорії витрат):

  | Гілка меню | Set `category` = |
  |------------|------------------|
  | Їжа | `Їжа` |
  | Продукти | `Продукти` |
  | Ні за що | `Ні за що` |
  | Пальне | `Пальне` |
  | Хотілки | `Хотілки` |
  | Здоров'я | `Здоров'я` |

### 3. Надіслати запит до API

- Додайте дію **«Отримати вміст URL» (Get Contents of URL)**.
- **URL:** `https://<DOMAIN>/api/quick-add`
- **Method:** `POST`
- **Headers (Заголовки):**
  - `X-API-Key` = `<ВАШ_КЛЮЧ>` (персональний ключ з Налаштувань)
  - `Content-Type` = `application/json`
- **Request Body:** `JSON`
  - `category` (Text) = змінна **`category`** (з кроку 2)
  - `amount` (Number) = **Наданий ввід (Provided Input)** з кроку 1
  - `note` (optional): якщо хочете — текстова дія для введення нотатки

Підсумковий JSON виглядає так:
```json
{ "category": "Їжа", "amount": 250, "note": "опціонально" }
```

### 4. (Необовʼязково) Показати підтвердження

- Додайте дію **«Показати сповіщення» (Show Notification)**.
- Текст: вміст відповіді або просто "Додано ✓"
- Сервер повертає:
  ```json
  { "ok": true, "date": "2026-09-25", "transaction": { … }, "totals": { "income": 1000, "expenses": 250, "balance": 750 } }
  ```

### 5. Винести на головний екран

- Назвіть Shortcut, наприклад **«➕ Витрата»**.
- Меню Shortcut → **Поділитися** → **На екран «Початок» (Add to Home Screen)**.
- І/або привʼяжіть до **кнопки Дії (Action Button)** на iPhone 15 Pro і новіших.
- І/або додайте **віджет Shortcuts** на екран блокування (Lock Screen).

## Скасування останнього швидкого додавання

Щоб скасувати останній швидкий запис сьогодні через Shortcut:

- Додайте дію **«Отримати вміст URL» (Get Contents of URL)**.
- **URL:** `https://<DOMAIN>/api/quick-add/last`
- **Method:** `DELETE`
- **Headers:**
  - `X-API-Key` = `<ВАШ_КЛЮЧ>`

Сервер повертає:
```json
{ "ok": true, "date": "2026-09-25", "removed": { … }, "totals": { "income": 1000, "expenses": 0, "balance": 1000 } }
```

Або на сторінці сьогоднішнього дня (🌅/📝 кнопка на головній) натисніть **↩️ Скасувати швидкий запис** — кнопка з'являється, коли за сьогодні є швидкий запис.

## Перевірка через термінал

Тестування API вручну (замість `<DOMAIN>` та `<ВАШ_КЛЮЧ>` встановіть реальні значення):

### Додавання запису

```bash
curl -s -X POST https://<DOMAIN>/api/quick-add \
  -H "X-API-Key: <ВАШ_КЛЮЧ>" \
  -H "Content-Type: application/json" \
  -d '{"category":"Їжа","amount":250,"note":"кава"}'

# Відповідь успіху:
# {"ok":true,"date":"2026-09-25","transaction":{…},"totals":{"income":1000,"expenses":250,"balance":750}}
```

### Скасування останнього

```bash
curl -s -X DELETE https://<DOMAIN>/api/quick-add/last \
  -H "X-API-Key: <ВАШ_КЛЮЧ>"

# Відповідь успіху:
# {"ok":true,"date":"2026-09-25","removed":{…},"totals":{"income":1000,"expenses":0,"balance":1000}}
```

## Коди помилок

| HTTP | Помилка | Причина |
|------|---------|---------|
| 200 | (успіх) | Запис додано / скасовано |
| 401 | `Невірний ключ API` | Помилкова чи відсутня `X-API-Key` або ключ відкликаний |
| 400 | `Невідома категорія` | Категорія не існує, архівована, належить іншому користувачу або назва не збігається з жодною активною |
| 400 | `Сума має бути додатнім числом` | Сума ≤ 0, не число, чи занадто велика |
| 404 | `Немає швидких записів за сьогодні` | Немає чого скасовувати (DELETE /last) |
| 400 | `Неоднозначна категорія: вкажіть kind (income або expense)` | Назва збігається з обома активними категоріями (доходу і витрат) |
| 400 | `Невірний тип категорії` | `kind` мав значення, яке не є `income` чи `expense` |
| 400 | `Нотатка — до 200 символів` | Нотатка перевищує 200 символів |
| 400 | `Невірний формат запиту` | JSON не парситься або структура невірна |

## Поради

1. **Назва категорії чутлива до регістру?** Ні! Запит робить case-insensitive пошук (`Їжа` = `їжа` = `ЇЖА`). Проте рекомендуємо використовувати назву так, як вона відображається в Налаштуваннях.

2. **Забули ключ?** Він показується один раз при генерації. Якщо забули, зайдіть в **Налаштування** → **⚡ Швидке додавання** → **🔄 Перегенерувати ключ** — старий ключ перестане працювати.

3. **Категорія архівована?** Архівовані категорії не приймаються в quick-add; скористайтеся активною категорією або створіть у Налаштуваннях нову категорію з такою ж назвою (якщо не досягнуто ліміту 5/10).

4. **Альтернатива: id категорії.** Якщо в меню Shortcut можна використовувати числове id замість назви — це також спрацює:
   ```json
   { "category": 12, "amount": 250 }
   ```
