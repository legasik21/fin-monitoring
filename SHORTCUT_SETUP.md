# 📱 Швидке додавання витрат з головного екрана iPhone (Apple Shortcut)

Цей застосунок надає endpoint `POST /api/quick-add`, який дозволяє додати витрату
або дохід **одним дотиком** з головного екрана iPhone — через застосунок
**Команди (Shortcuts)**. Нативний iOS-віджет із вебзастосунку зробити неможливо,
тому Apple Shortcuts — це правильний підхід.

> Веб-віджет не може писати в застосунок напряму, тому використовуємо Shortcut, який
> робить HTTP-запит до API.

---

## Що знадобиться

| Значення | Де взяти |
|----------|----------|
| `<DOMAIN>` | `fin-mon.cyberskill.online` (домен розгорнутого застосунку) |
| `<QUICK_ADD_TOKEN>` | значення `QUICK_ADD_TOKEN` з `.env` на сервері (НЕ пароль входу) |

> ⚠️ `<DOMAIN>` і `<QUICK_ADD_TOKEN>` мають **точно збігатися** з тим, що розгорнуто на
> сервері. Токен — це секрет: не діліться ним і не публікуйте.

Endpoint приймає JSON `{ "category": "<key>", "amount": <число> }`, де `category` — один із:

| Кнопка в меню | `category` key |
|---------------|----------------|
| Їжа | `food_out` |
| Продукти | `food_market` |
| Ні за що | `no_reason` |
| Пальне | `gas` |
| Хотілки | `wants` |
| Здоров'я | `health` |
| (дохід) | `income_main` |
| (чайові) | `income_tips` |

Сума **додається** до сьогоднішнього дня (день створюється відкритим, якщо його ще немає),
тож ви можете далі редагувати його у застосунку.

## Побудова Shortcut крок за кроком

Відкрийте застосунок **Команди (Shortcuts)** → **+** (новий Shortcut) → **Додати дію**.

### 1. Запитати суму
- Додайте дію **«Запитати ввід» (Ask for Input)**.
- Тип вводу: **Число (Number)**.
- Підказка (Prompt): **`Сума?`**

### 2. Вибрати категорію
- Додайте дію **«Вибрати з меню» (Choose from Menu)**.
- Пункти меню (Add new item): **Їжа**, **Продукти**, **Ні за що**, **Пальне**, **Хотілки**, **Здоров'я**.
- У **кожній** гілці меню додайте дію **«Задати змінну» (Set Variable)**:
  - назва змінної: `category`
  - значення — відповідний ключ:

  | Гілка меню | Set `category` = |
  |------------|------------------|
  | Їжа | `food_out` |
  | Продукти | `food_market` |
  | Ні за що | `no_reason` |
  | Пальне | `gas` |
  | Хотілки | `wants` |
  | Здоров'я | `health` |

### 3. Надіслати запит до API
- Додайте дію **«Отримати вміст URL» (Get Contents of URL)**.
- **URL:** `https://<DOMAIN>/api/quick-add`
- **Method:** `POST`
- **Headers (Заголовки):**
  - `X-API-Key` = `<QUICK_ADD_TOKEN>`
  - `Content-Type` = `application/json`
- **Request Body:** `JSON`
  - `category` (Text) = змінна **`category`** (з кроку 2)
  - `amount` (Number) = **Наданий ввід (Provided Input)** з кроку 1

Підсумковий JSON виглядає так:
```json
{ "category": "<category>", "amount": <amount> }
```

### 4. (Необовʼязково) Показати підтвердження
- Додайте дію **«Показати сповіщення» (Show Notification)**.
- Текст: вміст відповіді **«Отримати вміст URL»** — сервер повертає:
```json
{ "ok": true, "date": "2026-06-23", "totals": { "income": 6670, "expenses": 2400, "balance": 4270 } }
```

### 5. Винести на головний екран
- Назвіть Shortcut, напр. **«➕ Витрата»**.
- **На головний екран:** меню Shortcut → **Поділитися** → **На екран «Початок» (Add to Home Screen)**.
- І/або привʼяжіть до **кнопки Дії (Action Button)** на iPhone 15 Pro і новіших.
- І/або додайте **віджет Shortcuts** на екран блокування (Lock Screen).

## Перевірка через термінал (необовʼязково)

```bash
curl -s -X POST https://<DOMAIN>/api/quick-add \
  -H "X-API-Key: <QUICK_ADD_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"category":"gas","amount":250}'
# -> {"ok":true,"date":"...","totals":{"income":...,"expenses":...,"balance":...}}
```

Помилки:
- `401` — невірний або відсутній `X-API-Key`.
- `400` — невідома `category` або сума ≤ 0 / не число.
